# Solidity Examples Workspace

This workspace collects several Solidity example projects and deployment helpers that were adapted from the Updraft Cyfrin Solidity course and accompanying GitHub materials.

Key references
- Updraft Cyfrin Solidity course: https://updraft.cyfrin.io/courses/solidity
- Course GitHub materials: https://github.com/Cyfrin

Repository layout (top-level folders)
- `remix-simple-storage/` — simple storage contract and Remix-focused README
- `remix-fund-me/` — FundMe contract and price-converter examples
- `foundry-simple-storage/` — Foundry examples, scripts, and tests
- `solidity-cyfrin-FULL-impl/` — fuller implementation and Remix helpers
