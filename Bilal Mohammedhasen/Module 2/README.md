# Module 2 — Sending Ether & Transaction Safety
![Module 2 Completion](Module-2%20Course%20Completion.png)

Module 2 focuses on sending Ether, handling transaction reverts, calldata patterns, and a multi-step escrow exercise.

Top-level lessons:
- `1_sending-ether` — store owner, receive Ether, tip owner, charity, self-destruct examples
- `2_reverting-transactions` — constructor reverts, only-owner checks, owner modifier
- `3_practice-calldata` — call/function signature calldata exercises
- `4_escrow` — progressive escrow implementation (setup, constructor, funding, approval, security, events)

Run tests the same way as Module 1 with `forge test` from the repo root.
