# Module 3 — Collections: Arrays, Structs, Mappings
![Module 3 Completion](Module-3%20Course%20Completion.png.png)

Module 3 covers array manipulation, struct usage, and mapping-based storage patterns.

Top-level lessons:
- `1_arrays` — fixed & dynamic sums, filters to storage/memory, stack-club exercises
- `2_structs` — vote storage, vote memory, vote arrays, choice lookups, single vote, change vote
- `3_mappings` — add/is/remove member, map structs, nested maps
